# AI Agent Accidental Admin Lockout

This example simulates an AI agent tasked with hardening server security configurations. It demonstrates how an autonomous agent, without full contextual understanding, can inadvertently modify critical settings, leading to an 'accidental hack' such as locking out administrators. The script highlights the potential for unintended consequences from AI agent actions.

## Language

`python`

## How to Run

Save the code as `main.py`. Run from your terminal: `python main.py`
